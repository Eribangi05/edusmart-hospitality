# Edusmart Hospitality

Multi-tenant hospitality SaaS for Rwanda (hotels, guest houses, restaurants, bars, shops).

- `/backend`: Laravel API, tenant console and super-admin console (planned)
- `/android`: native Kotlin / Compose app, offline-first (planned)
- `/api-spec`: OpenAPI contract, the source of truth for the API
- `/docs`: architecture, master prompt, runbooks

Package ID: `com.edusmartconsult.hospitality`. Currency: RWF (no minor unit). Languages: en, fr, rw.
Payments: MTN MoMo (sandbox first). Web: hospitality.edusmartconsult.com.

See `docs/MASTER_PROMPT.md` for the build plan and `docs/architecture.md` for the design.
